# Med Handoff Card — build handoff

## Delivered

- A Vite + TypeScript offline PWA in `dist/`, with IndexedDB as the only
  medication-record store.
- Large time-of-day dose board: each scheduled dose can be marked Taken, Held,
  or Unknown with a note and a visible same-day change record.
- Editable current regimen (medicine, dose, directions, schedule), shift note,
  recipient name, responsive print view, local QR handoff, JSON/CSV backup,
  encrypted AES-GCM JSON export, and encrypted-import restore.
- Manifest, maskable SVG icons, cache-versioned hand-written service worker,
  offline fallback, asset precache message, and update-ready reload toast.
- `/privacy` and `/terms` routes plus a $9 one-time Plus presentation with the
  Sociobot checkout, license query capture, device restore, daily verification,
  and offline optimistic unlock behavior. The free safety workflow is ungated.
- Product-specific dithered/halftone print visual system recorded in
  `.factory/design.md`.
- Original illustration at `src/assets/handoff-tray.webp` (170 KB). It was
  generated by `/opt/fleet/lib/gen-image.sh` on 2026-08-28; its sidecar has the
  exact prompt/deployment metadata. It was visually reviewed for text, brands,
  people, and medical claims before inclusion.

## Verification performed

- `npm test` — 2 unit tests pass (dose-state replacement, handoff/CSV output).
- `npm run build` — passes; output root is `dist/index.html`.
- Production assets: initial JS is **44.92 KB** (17.33 KB gzip), CSS is
  **10.97 KB** (3.31 KB gzip), and the decorative hero is **170.45 KB**;
  all within the static-PWA budgets.
- Playwright on a 390 × 844 viewport: added a medicine, marked a dose Taken
  with a note, observed no console/page errors and no horizontal overflow
  (`scrollWidth = clientWidth = 390`).
- Production Playwright offline check: visited once, waited for the service
  worker cache, set the context offline, reloaded, and the normal board loaded
  successfully.
- Axe Playwright check on the mobile empty state: **0 serious/critical
  violations**. Semantic title/lang/main/one-h1, skip link, focus states,
  labels, reduced-motion behavior, contrast tokens, and printed alt text were
  manually checked in the rendered product.

## Known gaps / next steps

- Named multi-profile storage is described by the Plus offer but is not
  implemented in v1; the single-profile free handoff workflow is complete.
  Implement profile switching only after the factory has registered and tested
  the paid product flow.
- QR handoffs intentionally contain plain data so ordinary phone scanners can
  use them. The UI warns users; encrypted QR is not offered because it would
  undermine quick caregiver handoff.
- Lighthouse was not available in this container. Build-size budgets, mobile
  browser, axe, console, and offline checks are recorded above; run a mobile
  Lighthouse audit on the deployed URL before launch if factory policy requires
  a numeric score.
